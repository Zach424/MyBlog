# 从同一事件模型派生首页摘要，并用路由样式保护全局预算

关联：[[STATUS|当前项目状态]] · [[0120-homepage-recent-activity|Iteration 0120]] · [[0119-event-ledger-semantics|事件账本语义]]

## 摘要不是第二份数据

完整活动页已经拥有确定性事件流：首页只需要改变观察窗口，不需要重新定义事件。

```text
公开记录
  → createContentActivity
  → 已排序日期组
  → flatMap 成全局事件流
  → slice(0, 3)
  → 首页最近活动
```

如果页面按每个日期组各取一项，或重新比较 `updatedAt`，很容易在同日多事件、模式决胜或未来排序调整时与完整账本漂移。正确边界是先完成领域投影，再由消费者限制数量。

## 稳定语义属性优于样式类

CSS Module 类名由构建生成，适合隔离样式，不适合作为跨构建生产测试协议。页面为活动组、事件和模式保留 `data-home-activity-*` / `data-activity-*`；测试据此检查数量与语义，视觉类可以自由重构。

```text
className   → 布局和视觉实现
data-*      → 可观察的页面语义契约
time/link   → 原生内容与导航语义
```

这也能避免测试为了选择节点而把内部哈希或长类名冻结成公共 API。

## 全局 CSS 是共享预算

全局样式接近 100 KB 时，新增一个页面区块不应直接提高阈值。先按责任检查规则：只被 `/activity` 使用的节点、轨道、断点和事件布局应该进入该路由的 CSS Module；跨页面 Token、shell、排版基础和真正共享组件才留在全局文件。

本轮迁移后：

```text
globals.css   99,995 B → 95,383 B
恢复余量                    4,612 B
```

路由级样式并非免费，它仍会影响对应页面资源；它的价值是隔离变化、减少无关页面负担，并让全局硬门继续具有意义。

## 轨道文字需要物理留白

横向规则线与文字共享同一高度时，即使结构正确也会降低可读性。给模式和日期使用 Canvas 背景及少量内边距，可以在轨道上形成稳定缺口；比负 margin 或随断点移动文字更少依赖字体度量。手机端转为纵向轨道后，同一 DOM 和标签仍可复用。

视觉验收应检查的不只是事件数量，还包括：

- 规则线是否穿字；
- 节点是否与轨道同心；
- 中文长标题是否自然换行；
- 横向与纵向轨道是否保持同一顺序；
- 根 `scrollWidth` 是否等于视口；
- 控制台是否存在 CSS 404/MIME 错误。

## 构建进程也属于验证环境

`next start` 会读取 `.next` 中带指纹的构建产物。如果在它运行时重新构建，同一进程可能返回新 HTML 清单却找不到旧 CSS chunk，浏览器表现为局部无样式和 MIME 错误。此时应先核对端口监听进程、HTML 引用和磁盘 chunk，再决定是否修改代码。

可靠流程是：停止旧生产进程 → 完整构建 → 启动新进程 → 使用新浏览器会话复测。验证环境的版本一致性与应用代码同样重要。

## 可复用经验

当同一领域数据需要“完整视图”和“首页摘要”时，保持一个排序完成的只读模型，让消费者只控制窗口大小。样式隔离与测试契约也应分层：CSS Module 管视觉边界，稳定 `data-*` 管可观察语义，原生 HTML 管访问与导航。性能基线仍必须来自已部署版本，不能用本地输出替自己的增长背书。
